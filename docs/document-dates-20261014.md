# Source-backed document dates

Four existing PDF covers provide explicit month-level dates: the investor factsheet is dated July 2026; both corporate brochures are dated September 2026; the progress report identifies August 2026 with an October 2026 update. These dates are now recorded separately from version identifiers and approval dates, and appear in French/English static download cards and the registry-driven explorer.

Date evidence records the exact file fingerprint and PDF page 1 as its source. When a file fingerprint changes, the old date metadata is removed; the release audit requires review of that source. Existing version identifiers remain intact and missing version numbers remain unspecified. No PDF contents were changed.

Validation: ten document metadata tests, production build and migration verification, four date/fingerprint checks, existing download-language and public-navigation audits, and browser inspection of all 14 dynamic library cards. The original dated PDFs remain company-published statements; their dates and file integrity do not independently establish corporate appointments, financing or operating results.
