# Formation-stage company descriptions

The French and English machine-readable company description omitted the formation-stage qualification already displayed on the homepage. The English homepage search preview also described the whole chain as built in Chad.

The build now aligns the existing full company descriptions with the published formation-stage programme, explicitly qualifying project and capacity targets. Corporate homepage search/social previews and their WebPage descriptions use consistent wording. Company names, identifiers, other organizations, reference-only objects, Arabic content and subsite previews are preserved.

Four regression checks cover both languages, preserved fields, all homepage preview channels, idempotence, references, other organizations and subsite previews. This is a publication-consistency change; it does not verify registration, approvals, financing or operational status, and does not guarantee how search engines display snippets.
